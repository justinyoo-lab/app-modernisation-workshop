# Security Policy

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

Instead, please report them to: **security (at) devkimchi (dot) com**

Include the following in your report:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

The maintainers will review the report and coordinate a response before public
disclosure. Please do not include unrelated personal or sensitive information.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest commit | Yes |

## Disclosure Policy

When a vulnerability is confirmed, maintainers will coordinate a fix and
disclosure with the reporter. Any upstream sample code remains subject to its
original project's security and disclosure policies.
